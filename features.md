# Rules of Conduct

- Everything need to be have a meaning.
- Simpler, useful, minimalism. These shall bring more understandable work station.

# Features

- Rounded Corners
    - Closer to nature.
- Colorful buttons on the corner of window
    - Firstly, it looks cool. Secondly, more simple design and more simple usage. Human could be able to easily imagine and
    see what is a color doing than what is a "icon" doing. And that brings a bit performance wise improvoment.
- Menubar
    - With menubar, design of windowing is more simplified. Detailed settings will be done from same place in every app.
    Not from their window. That simplifies usage of windows.
- Wastebin
    - When something being deleted, that thing will be added to the wastebin. And after a 14(?) days, an warning will pop up:
    "That thing will be deleted parmenently." Like iPhone wastebin in photos. If a 14(?) day countdown is not exists, wastebin
    is just a folder named wastebin. A useless piece of crap.
    - When wastebin is opened, app will show files that will be removed in 3 days in red theme.
